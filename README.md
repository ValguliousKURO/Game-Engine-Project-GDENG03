##  How to Run the Program

Follow these steps to get the project up and running:

1. **Open the Project:** Launch your IDE and open the project solution file.
2. **Run the Project:** If you are using Visual Studio, press **`Ctrl + F5`** to build and run the program without debugging.

---

## Project Structure & Key Files

* **Entry Point (Main Function):** `Rendering System\Game\main.cpp`
  
* **Core Logic & Test Cases:** `Rendering System\Game\MainGame.cpp`

> **Note for Reviewers:** `MainGame.cpp` is the primary file where object positions, transforms, and rotations were modified and configured for the test cases. Most test cases are commented out in this file. Some were not there because I simply forgot to comment them out instead of deleting and I didn't get to commit them to the repo.
